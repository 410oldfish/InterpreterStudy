# InterpreterStudy

Learning compiler/interpreter development with *Crafting Interpreters* by Robert Nystrom, implemented in Rust.

## Project: rlox

A Rust implementation of the Lox interpreter from the book.

### Build & Run

```sh
cd rlox
cargo build
cargo run
```
